# Conditional fleet anomaly ranking

本题研究设备群巡检的无监督异常排序。train为无标签历史观测，test为待检观测；记录彼此无时间顺序。正常测量随两维工况和设备身份变化，训练设备样本量可不均，训练混入少量异常，测试工况分布可偏移。故障既可能表现为单通道偏离，也可能表现为通道联合关系失配；null表示未观测，不等于零，缺失可随工况改变，故障受影响通道也可能被遮蔽，因此不要求完美分类。观测未经标准化，传感器量纲不同。公开接口契约：仅编辑environment/detector.py，入口rank_records(train,test)返回与test等长的有限实数列表，分数越大越异常；内部算法、参数、函数组织自行决定。固定cli.py通过标准输入接收一个UTF-8 JSON对象，顶层恰含train和test，向标准输出输出一个恰含scores的JSON对象，允许首尾空白，不得输出日志；诊断可写stderr。每条记录恰含unit、context、values：unit为不透明非空字符串，context为两个有限实数，values为六个有限实数或null；每行至少两项被观测，所有测试设备在训练出现，每个传感器至少有一个训练观测。训练总量400至2400行，测试每设备40至120行，设备数4至12；工况绝对值不超过3，测量绝对值不超过10000。评测只送入合法输入，不另考查非法输入报错协议。候选不得依赖样本文件名、实例编号、评测种子或标签；开发标签仅用于开发诊断，不作为固定查表答案写入提交。训练与测试列表可重排，设备标识可一一改名，评分按实际记录对应关系计算；不规定算法内部排序方式。只提交detector.py的修改，README.md、LICENSE、cli.py、selftest.py保持不变，禁止额外提交文件及符号链接；Python生成的__pycache__在验收复制时忽略。评测为每个实例启动新进程，只复制起始环境固定文件和提交的detector.py，挂载系统Python标准库，清空环境变量，隔离网络、隐藏评测、参考程序与其他实例；允许在私有/tmp临时计算，不允许依赖进程间持久状态。运行平台为Linux，Python3.11或以上，单CPU、1GiB地址空间、每实例20秒墙钟及20秒CPU时间、stdout和stderr各最多1MiB；超限、非零退出或输出不是规定的有限数值数组时该实例计0分。改动固定文件、缺少提交文件或出现额外提交文件时整份提交计0分。评分在每个设备内比较风险分与故障干预标签：AUROC是正例分数超过负例的配对比例，同分计半胜；macro_auc为设备AUROC算术平均，worst_unit_auc为其中最小值。每设备按分数取前ceil(0.1*n)条，边界同分项按剩余额度除以同分条数计算分数命中，所得正例命中数除以该设备正例数为召回；macro_recall_at_10pct为设备召回算术平均。每个评测设备均同时包含正负例。实例分数为100乘以0.5*max(0,2*macro_auc-1)+0.25*max(0,2*worst_unit_auc-1)+0.25*macro_recall_at_10pct；总分为全部实例分数算术平均，无效实例保留在分母中。AUROC的随机排序锚点为0.5、完全排序锚点为1；召回取0至1，不按本批标签比例归一化，所以固定巡检额度下满分可能不可达。分数无二值及格线，更高更好；reference的oracle_threshold仅为提供方参考质量目标，不是候选零分条件。开发和隐藏各12个实例，均为load_shift、sparse_units、joint_fault、dropout四类各三次重复，分别突出工况偏移、设备样本不均、联合关系失配、较多缺失；两组输入范围和生成机制相同，仅随机种子、系数、设备标识、观测与故障位置不同。settings.parameters中repeats=3表示每类重复次数，sensor_count=6表示通道数，unit_count=8表示实交实例设备数，test_per_unit=75表示每设备测试行数，inspection_fraction=0.1表示巡检比例，families为四类实例名；这些参数两组一致。开发数据和答案在../eval_dev/inputs/与../eval_dev/answers/，从environment运行python3 cli.py < ../eval_dev/inputs/load_shift_137.json可单次推断，python3 selftest.py运行隔离开发自测，需预装bubblewrap并允许用户命名空间。解题不联网、不使用GPU或第三方Python包。solver工作时间上限2小时，完整隐藏验收预留5分钟，解释型起始环境无需编译；构建检查为python3 -m py_compile cli.py detector.py selftest.py，限30秒。
